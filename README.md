## 서비스 설명
"夜야 간(단한) (안)주 행(향해 간다)"는 술집에서 비싼 안주 대신, 집이나 편의점에서 쉽게 구할 수 있는 재료로 저렴한 안주를 만들 수 있다는 것을 알려주는 웹사이트입니다. 저가의 안주와 술을 추천해 가성비 좋은 술자리를 만들 수 있도록 도와줍니다.

### **목표 대상**
- **Target**: 젊은 층 / 대학생

### **차별화 포인트**
- **가성비**: 저가 안주 레시피 추천
- **다양한 기능**:
  - 실시간 순위 갱신 기능
  - 사용자 피드백을 반영한 좋아요 기능
  - 상황에 맞는 카테고리별 안주 추천
  - 저가의 안주에 맞는 술 추천

## 기능
- **실시간 인기 안주 랭킹**: 좋아요가 많은 순으로 랭킹이 실시간으로 업데이트됩니다.
- **좋아요 기능**: 각 안주 레시피에 좋아요 버튼이 있어, 사용자들이 좋아요를 누를 때마다 수가 증가합니다.
- **상황별 카테고리**: 다양한 상황에 맞는 저가 안주를 추천합니다.
- **저가 안주와 술 추천**: 각 안주에 적합한 술을 추천합니다.
- **레시피 세부 정보 제공**: 요리에 필요한 재료, 상세 조리법, 난이도 정보 등을 제공합니다.

## 기술 스택
- **프론트엔드**:  
  - **ReactJS**: UI 구성 및 사용자 상호작용을 위한 프론트엔드 라이브러리
  - **Styled-Component**: UI 스타일링을 위한 라이브러리
  - **Recoil**: 상태 관리를 위한 라이브러리
  - **Axios**: API 통신을 위한 라이브러리
- **백엔드**:  
  - **json-server**: 간단한 RESTful API 서버 구축
